Overview
--------

Nexacon provides SDKs for integrating audio/video calling, messaging, and device management into your applications.

Available SDKs
--------------

* **Flutter SDK** - Cross-platform audio/video calling for Android, iOS, Linux, macOS, and Windows

.. note::
   Additional SDKs for other platforms are in development and will be added here once tested and stable.

Core Features
-------------

* **Authentication** - User login, token management, and session handling
* **Calls** - Audio and video calling with WebRTC
* **Devices** - Register devices for push notifications
* **Rooms** - Group call management
* **Presence** - User online status and last seen

Platform Support

Related SDKs
------------

* **Nexacon Messaging SDK** - Real-time chat messaging with presence, typing indicators, and message history. See `nexacon-messaging docs <https://nexacon-messaging.readthedocs.io/>`_.
